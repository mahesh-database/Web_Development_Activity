# Bus and Train Ticket Booking Interface

## About the Project
This is a basic Bus and Train Ticket Booking Interface made using HTML and CSS. It allows users to view a simple travel booking form, check available services, see ticket fares, and view seat options.

## Features
- Select bus or train.
- Enter source and destination.
- Choose the travel date.
- Enter the number of passengers.
- View available buses and trains.
- Check departure time, arrival time, and ticket fare.
- View seat selection buttons.
- Enter passenger details.
- Simple and responsive design.

## Technologies Used
- HTML
- CSS

## How to Run the Project

1. Download or copy the project files.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in a web browser.
5. Explore the ticket booking interface.

## Purpose of the Project

The main purpose of this project is to learn the basics of HTML and CSS by creating a simple travel booking webpage.

## Limitations

- Tickets cannot actually be booked.
- The search button does not perform a search.
- Seat selection is only a visual design.
- Passenger details are not stored.
- No database or backend is connected.

# Project and Task Management Dashboard

## About the Project

This is a simple Project and Task Management Dashboard created using HTML and CSS. It helps users view project details, manage tasks, check deadlines, and track project progress.

## Features

- Project summary cards
- Total projects and tasks
- Team member details
- Project deadlines
- Progress indicators
- Task cards
- High, medium, and low priorities
- Kanban-style task columns
- Responsive layout for smaller screens

## Technologies Used

- HTML
- CSS

## Project Structure

```text
ProjectDashboard/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Create a folder named `ProjectDashboard`.
2. Create the `index.html` and `style.css` files.
3. Copy the respective code into each file.
4. Save both files.
5. Open `index.html` in a web browser.

## CSS Concepts Used

- CSS Grid
- Flexbox
- Colors and backgrounds
- Margins and padding
- Borders and shadows
- Media queries
- Progress indicators

## Limitations

This is a front-end design only. Tasks cannot be moved between columns, and project information is not saved.

# Business Analytics Dashboard

## About the Project

This is a basic Business Analytics Dashboard created using HTML and CSS. It displays business information such as revenue, users, sales, monthly performance, and recent activities.

## Features

- Business dashboard with sidebar navigation
- Revenue summary
- Total users and sales
- Business growth information
- Monthly sales bar chart
- Sales performance table
- Recent activity section
- Responsive layout for different screen sizes

## Technologies Used

- HTML
- CSS

## Project Structure

```text
BusinessDashboard/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Create a folder named `BusinessDashboard`.
2. Create `index.html` and `style.css`.
3. Copy the HTML and CSS code into the respective files.
4. Save the files.
5. Open `index.html` in a web browser.

## Concepts Used

- HTML headings and paragraphs
- CSS Grid
- CSS Flexbox
- Tables
- Sidebar navigation
- CSS media queries
- Colors, margins, padding, and borders

## Limitations

- All business figures are sample data.
- The charts do not update automatically.
- The navigation links are only for display.
- No database is connected.
